# teaching-theory-of-probability-2026
Лекции по теории вероятности для Тимирязевки и ИТМО

Структура репозитория:

| Путь | Что лежит |
|---|---|
| `lectures/` | Презентации лекций (`.pptx`) и методички к ним (`.md`, открываются в Obsidian) |
| `attachments/` | Ноутбуки семинаров `.ipynb` и иллюстрации к методичкам; студенты загружают ноутбуки в Google Colab сами («Файл → Загрузить блокнот») |
| `homework/` | Домашние задания с автопроверкой |
| `.github/workflows/` | GitHub Actions для автопроверки ДЗ |

Преподавательские версии с решениями в репозиторий не коммитятся.
