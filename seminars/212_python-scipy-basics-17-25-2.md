## Краткий рекап: шпаргалка Python

### 0. Среда

- Ноутбук помнит всё, что уже **выполнено**, в порядке выполнения, а не расположения ячеек. После «Перезапустить сеанс» память пуста — выполняйте сверху вниз.
- `import numpy as np`, `from scipy import stats` — подключить библиотеки под короткими именами.
- Ошибку читаем с **последней строки** traceback:
  - `NameError` — такого имени Python не знает (опечатка или ячейка с ним не выполнена);
  - `AttributeError` — у объекта нет такого имени после точки (например, `pdf` у дискретного закона);
  - `TypeError` — операция не подходит к типу данных (`"5" + 3`).

### 1. Переменные и типы

- `n = 10` — привязать имя `n` к объекту 10. Типы: `int`, `float`, `bool` (`True`/`False`), `str`, `None`; узнать — `type(x)`.
- Ячейка показывает только **последнее** выражение; остальное — через `print`. f-строка: `print(f"E = {X.mean():.3f}")`.
- Сравнение даёт `bool`: `n > 3` → `True`.

### 2. Коллекции

- Список: `ks = [0, 1, 2, 3]`, индексы с нуля: `ks[0]`, `ks[-1]`; срез `ks[1:3]` → `[1, 2]` (правая граница не входит); `len(ks)`.
- Словарь «ключ → значение»: `params = {"n": 10, "p": 0.3}`, `params["p"]`, `params.keys()`, `params.items()`.
- Цикл: `for key, value in params.items(): ...` — выполнить действие для каждой пары.

### 3. Функции

- Вызов со скобками: позиционные аргументы по порядку, именованные — по имени: `stats.binom.pmf(3, n=10, p=0.3)`.
- Сигнатура в документации `pmf(k, n, p, loc=0)`: `k, n, p` обязательны и идут в этом порядке, `loc=0` — значение по умолчанию.
- Результат функции можно сохранить: `prob = stats.binom.pmf(3, 10, 0.3)`.
- Справка: `help(stats.binom.pmf)` или `stats.binom.pmf?` в Colab.

### 4. Объекты и методы: распределение в SciPy

- `X = stats.binom(n=10, p=0.3)` — **замороженное** распределение: конкретный закон с зашитыми параметрами.
- Атрибут — без скобок (`X.kwds`), метод — со скобками (`X.mean()`). `X.mean` без скобок — сам метод, а не число.
- Без заморозки то же самое: `stats.binom.pmf(3, 10, 0.3)` = `X.pmf(3)`; разница только в том, где параметры.
- У нормального закона `stats.norm(loc=a, scale=σ)`: `scale` — **стандартное отклонение, не дисперсия**.

| Метод | Что считает |
|---|---|
| `X.pmf(k)` | $P(X=k)$, только у дискретных |
| `X.pdf(x)` | плотность $f(x)$, только у непрерывных |
| `X.cdf(x)` | $P(X\le x)$ |
| `X.sf(x)` | $P(X>x)$ |
| `X.ppf(q)` | квантиль уровня $q$ |
| `X.mean()`, `X.var()`, `X.std()` | $E(X)$, $\mathrm{Var}(X)$, $\sigma(X)$ |
| `X.rvs(size=..., random_state=...)` | выборка |

### 5. Массивы NumPy

- `np.array([3, 7, 1])`, `.shape`, `len`; `np.arange(0, 11)` — целые 0…10; `np.linspace(-6, 6, 200)` — 200 точек с концами.
- Операции сразу над всеми элементами: `x + 1`, `x ** 2`, `X.pmf(ks)`.
- Сравнение даёт маску: `x >= 5` → массив `True/False`; `x[x >= 5]` — отобрать элементы.
- `(x >= 5).mean()` — доля `True`, то есть **частота события в выборке**; `.sum()` — сколько их.
- «И» — `&`, «или» — `|`, скобки обязательны: `(x >= 3) & (x <= 7)`.

### 6. Выборка и теория

- `s = X.rvs(size=100_000, random_state=2026)` — массив наблюдений.
- Частота против вероятности: `(s >= 5).mean()` против `X.sf(4)`; для целочисленной величины $P(X\ge5)=P(X>4)$.
- Среднее и дисперсия выборки против теории: `s.mean()` и `X.mean()`, `s.var()` и `X.var()`.
- Одинаковое число в `random_state` — одинаковая выборка при каждом запуске.
