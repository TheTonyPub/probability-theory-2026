## Краткий рекап

### Классы в Python

- **Класс** — описание того, что умеет объект; **объект** — конкретный экземпляр: `U = Uniform(2, 5)`.
- `__init__(self, ...)` выполняется при создании объекта и сохраняет параметры: `self.a = a`.
- `self` — сам объект; методы получают его первым аргументом, а через него — параметры: `self.b - self.a`.
- **Наследование**: `class Uniform(Distribution):` — `Uniform` получает всё, что есть в `Distribution`.
- **Абстрактный класс**: `class Distribution(ABC)` и декоратор `@abstractmethod` из модуля `abc`. Метод только объявлен, написать его обязан наследник. Пока написаны не все абстрактные методы, объект не создаётся: `TypeError: Can't instantiate abstract class ...`.
- Наследовать можно по цепочке: `Uniform` → `ContinuousDistribution` → `Distribution`. Метод, написанный в промежуточном классе, есть у всех его наследников.
- `raise NotImplementedError("...")` — сообщить, что метод здесь не имеет смысла.

### Интерфейс распределения

| Метод | Что возвращает |
|---|---|
| `rvs(size, random_state)` | выборку из `size` наблюдений |
| `pdf(x)` | плотность $f(x)$ |
| `pmf(x)` | вероятность $P(X=x)$ |
| `cdf(x)` | $F(x)=P(X\le x)$ |
| `sf(x)` | $P(X>x)=1-F(x)$ |
| `ppf(q)` | квантиль уровня $q$: наименьшее $x$, при котором $F(x)\ge q$ |
| `mean()`, `var()` | $E(X)$, $\mathrm{Var}(X)$ |

Иерархия классов:

```
Distribution                      все 8 методов абстрактные
├── ContinuousDistribution        pmf готов: возвращает нули
│   └── Uniform, ...
└── DiscreteDistribution          pdf готов: бросает NotImplementedError
    └── ...
```

- У непрерывного закона $P(X=x)=0$ в каждой точке, поэтому `pmf` у всех непрерывных одинаковый и возвращает нули (в SciPy у непрерывных законов метода `pmf` нет совсем).
- У дискретного закона плотности нет, поэтому `pdf` у всех дискретных одинаковый и бросает `NotImplementedError`.

Договорённости для всех наших классов:

- методы принимают число или массив NumPy и возвращают результат той же формы;
- внутри своих классов `scipy` не используем, можно `numpy` и модуль `math`; SciPy нужен только для проверки.

### Равномерное распределение $U[a,b]$

$$
f(x)=\begin{cases}\dfrac{1}{b-a}, & a\le x\le b,\\[4pt] 0, & \text{иначе,}\end{cases}
\qquad
F(x)=\begin{cases}0, & x<a,\\[2pt] \dfrac{x-a}{b-a}, & a\le x\le b,\\[4pt] 1, & x>b,\end{cases}
$$

$$
E(X)=\frac{a+b}{2},\qquad \mathrm{Var}(X)=\frac{(b-a)^2}{12},\qquad x_q=a+q\,(b-a).
$$

В SciPy: `stats.uniform(loc=a, scale=b - a)` — сдвиг и длина отрезка, а не его концы.
