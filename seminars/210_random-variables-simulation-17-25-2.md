## Краткий рекап: формулы

### Как задаётся величина

| | Дискретная | Непрерывная |
|---|---|---|
| Чем задаётся | рядом $p_i=P(X=x_i)$ | плотностью $f(x)$ |
| Нормировка | $\sum p_i=1$ | $\int_{-\infty}^{+\infty} f(x)\,dx=1$ |
| Функция распределения $F(x)=P(X<x)$ | лесенка, $\sum\limits_{x_i<x}p_i$ | $\int_{-\infty}^{x}f(t)\,dt$, а $f(x)=F'(x)$ |
| Вероятность попадания | сумма $p_i$ по нужным $x_i$ | $\int_a^b f(x)\,dx=F(b)-F(a)$ |

### Числовые характеристики

| | Дискретная | Непрерывная |
|---|---|---|
| Математическое ожидание | $M(X)=\sum x_ip_i$ | $M(X)=\int x f(x)\,dx$ |
| Ожидание функции от $X$ | $M\big(g(X)\big)=\sum g(x_i)\,p_i$ | $M\big(g(X)\big)=\int g(x) f(x)\,dx$ |
| Дисперсия | $D(X)=M(X^2)-M^2(X)$ | то же, $M(X^2)=\int x^2 f(x)\,dx$ |
| Среднее квадратическое отклонение | $\sigma(X)=\sqrt{D(X)}$ | |

**Свойства:** $M(C)=C$, $M(CX)=C\,M(X)$, $M(X+Y)=M(X)+M(Y)$; $D(C)=0$, $D(CX)=C^2D(X)$, $D(X+C)=D(X)$.

**Смысл.** $M(X)$ — центр масс распределения и число, к которому приближается среднее арифметическое при многократном повторении опыта. $D(X)$ и $\sigma(X)$ показывают, насколько значения разбросаны вокруг $M(X)$.

**Бесплатные проверки ответа.** $M(X)$ лежит между наименьшим и наибольшим значением величины. $D(X)\ge0$. Если величина живёт на отрезке длины $L$, то $D(X)\le L^2/4$.

### Квантиль

**Квантиль уровня $q$** — такое значение $x_q$, левее которого лежит доля $q$ распределения: $F(x_q)=q$. Медиана — квантиль уровня $0{,}5$. Квантиль отвечает на вопрос «какой запас взять, чтобы его хватило в $q\cdot100\,\%$ случаев». В Python это метод `ppf`.

### `scipy.stats` в одной строке

`pmf`/`pdf` — вероятность или плотность, `cdf(x)` $=P(X\le x)$ (знак нестрогий, в отличие от лекции), `sf(x)` $=P(X>x)$, `ppf(q)` — квантиль, `mean()`, `var()`, `std()` — $M$, $D$, $\sigma$, `rvs(size=n)` — симуляция.
